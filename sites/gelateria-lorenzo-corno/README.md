# Gelateria Lorenzo Corno · München

Cineastischer Onepager für die Gelateria Lorenzo Corno (Hohenzollernstraße 44,
80801 München-Schwabing). Statisches HTML + CSS + Vanilla JS, keine Build-Tools.

## Inhalt

- `index.html` – Onepager: Vollbild-Hero (Ken-Burns), Impressionen, Szenen mit
  Parallax, Über Lorenzo, Sorten, Stimmen, Besuch/Karte
- `impressum.html` / `datenschutz.html` – Rechtsseiten (Platzhalter, vor Go-Live prüfen)
- `styles.css` – Design (warme Palette, Fraunces + Nunito Sans, cineastisch)
- `app.js` – Intro, Scroll-Reveals, Parallax, Nav-Zustand, mobiles Menü
- `img/` – echte Fotos aus dem Google-Profil, freigestellt & aufbereitet
- `gelateria-lorenzo-corno-komplett.html` – alles-in-einer-Datei (zum Öffnen/Verschicken)
