# Gelateria Lorenzo Corno · München

Onepager für die Gelateria Lorenzo Corno (Hohenzollernstraße 44, 80801 München-Schwabing).
Statisches HTML + CSS + Vanilla JS, keine Build-Tools nötig.

## Inhalt

- `index.html` – Onepager (Hero, Über Lorenzo, Sorten, Bewertungen, Besuch/Karte)
- `impressum.html` / `datenschutz.html` – Rechtsseiten (Platzhalter, vor Go-Live prüfen)
- `styles.css` – Design (warme Creme-/Bernstein-Palette, Fraunces + Nunito Sans)
- `app.js` – Intro-Animation, Scroll-Reveal, Zähler, mobiles Menü, Scroll-Progress
- `img/` – Fotos (Ausschnitte aus vom Kunden bereitgestellten Aufnahmen des
  Google-Profils; vor Go-Live idealerweise durch Original-Fotos des Inhabers ersetzen)
