# Fotos für die Café-Elisa-Seite

Hier die Original-Fotos des Cafés ablegen (z. B. vom Café direkt, von Google Maps
oder vom Instagram-Kanal @cafeelisa_ – **nur mit Erlaubnis des Cafés verwenden**).

Solange ein Foto fehlt, zeigt die Seite automatisch einen hübschen rosa
Platzhalter („Foto folgt") – nichts wirkt kaputt. Sobald die Datei mit dem
richtigen Namen hier liegt, erscheint das Foto von selbst.

## Benötigte Dateien

| Datei | Verwendung | Empfehlung |
|---|---|---|
| `hero.jpg` | Großes Hintergrundbild Startseite | Querformat, min. 1920 px breit (Fassade oder Innenraum) |
| `cafe-aussen.jpg` | Startseite „Willkommen" | Hochformat, die rosa Fassade |
| `event.jpg` | Startseite Event-Band | Querformat, gedeckte Feier-Tafel |
| `event-1.jpg` | Eventseite oben | Hochformat, dekorierte Feier |
| `event-2.jpg` | Eventseite unten | Hochformat, Bestelltorte |
| `g1.jpg` – `g12.jpg` | Galerie | Quadratisch/beliebig, je ca. 1200 px |

Motiv-Vorschläge für die Galerie stehen als Alt-Texte in `galerie.html`
(Fassade, Innenraum, Frühstück, Torte, Bubble Waffel, pinke Latte, Eisbecher,
Blumendeko, Crêpe, Feier-Tisch, Vitrine, Terrasse).

JPGs vor dem Upload am besten auf ~200–400 KB komprimieren (z. B. squoosh.app).
