> Hinweis: In der htmlpreview-Vorschau rendert jede Seite korrekt, aber das
> **Klicken von Seite zu Seite** funktioniert dort nicht zuverlässig. Für die
> vollständige Website mit funktionierender Navigation → lokal oder GitHub Pages/Vercel:

### Lokal (volle Navigation)
```bash
cd sites/a-plus-s-autoservice
python3 -m http.server 8000
# http://localhost:8000
```

### GitHub Pages / Vercel
- **GitHub Pages:** Settings → Pages → Source „Deploy from a branch" → Ordner `/ (root)`
  → `https://konrad01234.github.io/webseiten-verkaufen/sites/a-plus-s-autoservice/`
- **Vercel:** neues Projekt, Root Directory `sites/a-plus-s-autoservice`, Preset „Other".

## Fotos

Verwendet werden die **echten Fotos** der Werkstatt (Google-Betriebsfotos: Bauteile,
Bremse, Fahrwerk, Reifen) sowie das **echte Firmenschild/Gebäude** und das **echte Logo**.
Lizenzfreie Web-Stockfotos ließen sich in dieser Umgebung nicht laden (externe Bild-Seiten
sind netzwerkseitig gesperrt). Weitere Fotos einfach als Dateien in den Ordner `img/` legen –
dann binde ich sie an den passenden Stellen ein.
